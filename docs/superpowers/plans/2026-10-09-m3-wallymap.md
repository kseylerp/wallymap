# WallyMap Milestone 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn WildMap into WallyMap: Wally's design system and map language (route gradients, darts, mile markers, teardrop pins), 3D terrain, a time scrubber with play, route preview playback with an elevation profile, compare-over-time, and research-tool exports, on top of the Milestone 2 layers and inspect card.

**Architecture:** Visual tokens move to Wally's values in `app/globals.css`; map styling is split into pure spec builders (`lib/render/wally/*.ts`: gradients, darts, markers, pins, terrain, sky) consumed by `MapCanvas`/`mapTiles`/`deck.ts`. Time, playback, and compare are reducer state (`MapState.time`, `MapState.playback`, `MapState.compare`) driven by the layer panel, the scrubber, and three new agent tools (`set_time`, `route`, `compare`); the renderer derives per-step layer filters and tile URLs from that state.

**Tech Stack:** as before, plus `@deck.gl/aggregation-layers` (heat already), `@turf/along`/`@turf/length`/`@turf/bearing` (small, tree-shaken) for route math, Lucide icons, Mapbox `sky` layer and `queryTerrainElevation`.

**Spec:** `docs/superpowers/specs/2026-10-09-wallymap-m3-design.md` (binding), with `2026-10-09-wildmap-restyle.md` for anything M3 does not override.

## Global Constraints

- Tokens only via CSS variables; exact Wally values from the spec §2. No raw hex in components (tests grep for it).
- Pins/lines/polygons follow spec §3 numbers exactly (casing 7 / line 4.5; darts 16px every ~500 m max 12; pin 34×44, head r15, ring 2px).
- Every new tool is typed with zod and never throws; outputs are echoed data the browser maps to actions (same pattern as `set_view`).
- No clustering. No new persistent storage. Time filtering is client-side for GeoJSON; tiles re-request per step with a 150 ms debounce.
- `pnpm test`, `pnpm typecheck`, `pnpm lint` (0 warnings), `pnpm build`, `pnpm e2e` (always-run test) pass after every task. Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. The scrubber must not drop features lacking `t` when a window is active: layers without `t` stay fully visible (Task 7).
2. Playback must stop cleanly on route removal, basemap swap, and tab hide (`visibilitychange`), never leaving the camera in follow pitch (Task 8).
3. Compare swipe must clip both the Mapbox layers and the deck overlay consistently (Task 9).
4. Dark mode must restyle glass, cards, and the Mapbox label halo without breaking contrast (Task 1).
5. Pins at >300 features must fall back to dots without a frame drop (Task 4).
