# MapAgent Milestone 1: Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployable Next.js app where a user asks a question in a chat rail and the agent draws OpenStreetMap trails on a Mapbox map, with the layer registry, tool generation, cache, and renderer that every later layer plugs into.

**Architecture:** One Next.js app on Vercel. `layers/` holds one file per data source conforming to the `Layer` contract; `layers/index.ts` turns them into agent tools and an HTTP route. `/api/chat` runs a Vercel AI SDK tool loop whose tool results stream to the browser as data parts; a reducer folds them into `MapState`, and a pure factory turns `MapState` into deck.gl layers over Mapbox GL.

**Tech Stack:** Next.js (App Router, TypeScript strict), Vercel AI SDK (`ai` v5+, `@ai-sdk/anthropic`, `@ai-sdk/openai-compatible`), zod v4, mapbox-gl v3, deck.gl v9 (`@deck.gl/mapbox`), `@vercel/kv`, Tailwind, vitest, Playwright, pnpm.

**Spec:** `docs/superpowers/specs/2026-10-09-mapagent-design.md`

## Global Constraints

- TypeScript `strict: true`; no `any` in `layers/` or `lib/`.
- Features use the conventional optional properties `t` (ISO 8601 string) and `v` (number) exactly as named.
- API keys live only in server env vars; the browser receives only `NEXT_PUBLIC_MAPBOX_TOKEN`.
- The agent loop has `maxSteps: 8`.
- Cache TTL is 24 hours (`86400` seconds). Share links are Milestone 4; do not build.
- Every `LayerResult` carries a `citation` with `source`, `url`, and `retrieved`.
- Layer coverage is one of `"global"`, `"us"`, or `{ bbox }`.
- License file is MIT. Each layer declares its data `license` string.
- Every commit message ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Package manager is pnpm. Tests run with `pnpm test` (vitest) and `pnpm e2e` (Playwright).

## Review Focus

1. A bounding box wider than the layer's `maxAreaKm2` (OSM trails: 2500 km²) must return a `LayerError` telling the agent to zoom in, not hang Overpass. Pinned in Task 4.
2. A bounding box with `west > east` (antimeridian) or latitudes outside ±90 must be rejected by the shared `BBoxSchema` before any fetch. Pinned in Task 2.
3. Overpass returning HTTP 429 or 504 must surface as a chat error card with the layer id, and the agent must still finish its turn. Pinned in Tasks 3 and 7.
4. With no `KV_REST_API_URL` set (local dev, contributors), the cache must fall back to in-memory and never throw. Pinned in Task 3.
5. With no `NEXT_PUBLIC_MAPBOX_TOKEN`, the canvas must show a setup message naming the variable instead of a blank map. Pinned in Task 8.

### Task 3: Cached, rate-limited fetch

**Files:**
- Create: `lib/fetch/cache.ts`, `lib/fetch/bucket.ts`, `lib/fetch/index.ts`, `lib/fetch/cache.test.ts`, `lib/fetch/bucket.test.ts`
- Modify: `layers/types.ts` (replace `fetch: typeof fetch` with `fetch: CachedFetch`)

**Interfaces:**
- Produces:
  - `CachedFetch = (url: string, init?: RequestInit & { cacheKey?: string; ttlSeconds?: number }) => Promise<Response>`
  - `createCache(): Cache` where `Cache = { get(key): Promise<string | null>; set(key, value, ttlSeconds): Promise<void> }`; returns a KV-backed cache when `KV_REST_API_URL` and `KV_REST_API_TOKEN` are set, else an in-memory `Map` with expiry.
  - `createBucket({ capacity: number; refillPerSecond: number }): { take(): Promise<void> }` token bucket that awaits until a token is free.
  - `createLayerFetch(layerId: string, opts?: { capacity?: number; refillPerSecond?: number; ttlSeconds?: number }): CachedFetch`. Default capacity 5, refill 1/s, ttl 86400. Cache key defaults to `${layerId}:${method}:${url}:${bodyHash}`. Only 2xx responses are cached. Non-2xx responses are returned as-is (callers map to `LayerError`).
  - `cacheKeyFor(layerId: string, bbox: BBox, input: unknown): string` rounding bbox to 3 decimals and JSON-stringifying sorted input keys.
